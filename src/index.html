Demucs 4-stem model
This engine separates four broad stems: vocals, drums, bass and other. Lead/backing vocals, harmonies, and male/female splits need separate specialist models and are not active yet.

HTDemucs v4 runs inside a browser worker using locally hosted ONNX Runtime files. The model and runtime are built into this site; no paid inference API is used. Processing speed depends on your phone.
